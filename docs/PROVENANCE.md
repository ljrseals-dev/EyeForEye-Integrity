# Provenance and disclosure boundary

## Authorship

The repository's MIT license identifies Lewis James Seals Jr. as the copyright holder for the project files covered by that license. Git commit history remains the authoritative record of changes made in this repository.

## SPACE discussion

This project may refer to a SPACE concept and related patent-oriented technical discussion. The existence of technical notes or a provisional-patent specification template in another repository is not evidence of filing. No patent application number, filing receipt, grant, or enforceable pending status is asserted here.

Any public technical description must be checked against the actual disclosure record before publication. Keep unpublished claims, enabling implementation details intended for a filing, and confidential correspondence outside this repository until reviewed.

## External materials

Before importing code, models, phoneme data, recordings, sample banks, or datasets, record:
- source and retrieval location;
- author or rights holder, when known;
- exact version or commit/hash;
- license and redistribution permissions;
- modifications and required notices.

Do not infer that a repository license covers separately supplied assets.

## Excluded material

This sanitized baseline does not include private archives, credentials, private keys, personal data, unpublished patent disclosures, or the `mouth-bottom` ZIP archive. Its location and provenance have not been verified for this build.
